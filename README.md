# CeylonMart

### Sri Lankan Commerce, Connected.

CeylonMart is a modern e-commerce platform built using
Microservices Architecture and Event-Driven Architecture.

The project focuses on learning and implementing distributed
systems using Apache Kafka, Spring Boot, and Node.js.

## Technology Stack

- Frontend: React + TypeScript
- Backend: Spring Boot + Node.js
- API Gateway: Node.js + Express
- Messaging: Apache Kafka
- Databases: PostgreSQL + MongoDB
- Infrastructure: Docker
- Monitoring: Prometheus + Grafana
- Logging: Grafana Loki

## Architecture

CeylonMart follows a Monorepo structure containing the
frontend, backend microservices, infrastructure,
shared event contracts, and documentation.
